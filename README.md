## 🌸 About Me

I turn mathematical ideas into models that run. I'm doing a Master's degree in
**Applied Mathematics and Machine Intelligence**, after a background in
**Embedded Computer Science**. That mix taught me to care about both the theory
behind a model and the code that makes it work.

I like projects where **mathematics, data and intelligent models** come
together to solve practical problems, and I learn by building: running
experiments, analyzing data and understanding *why* a result looks the way it
does.

> 💭 *A good AI project starts with the data and the problem. The model comes last.*
